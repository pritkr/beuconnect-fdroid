# beuconnect-fdroid

Self-hosted F-Droid repository for [BEUConnect](https://github.com/pritkr/beuConnect),
served over GitHub Pages.

- Repository URL: `https://pritkr.github.io/beuconnect-fdroid/repo`
- Landing page: `https://pritkr.github.io/beuconnect-fdroid/`
- Package: `org.beuconnect.app`
- Index signing key SHA-256:
  `7B:3F:3E:CE:F7:C6:FC:EA:99:D3:C6:34:E8:EA:71:5E:18:0E:A8:8D:A3:2F:57:2A:62:BE:AC:49:BA:8E:69:8E`

## What lives here

| Path | Owner |
|---|---|
| `repo/` | Generated by `fdroid update` in the app repo's publish step. Never edited by hand. |
| `index.html` | Hand-written landing page. |
| `repo/org.beuconnect.app_*.apk` | The signed release APK, versionCode 2 (1.1.0). |

## Publishing an update

From a checkout of the app source:

```sh
./scripts/publish-fdroid.sh v1.2.0
```

The script copies the release APK and fastlane graphics into a scratch
fdroidserver directory, runs `fdroid update --clean`, restores the repo icon,
and replaces `repo/` here. Commit the result.

## Signing

The repo index is signed with `~/.config/beuconnect/fdroid-repo.jks`. That key is
the trust anchor for every client that added this repository — losing it means
each user has to remove and re-add the repo. Back it up offline.
